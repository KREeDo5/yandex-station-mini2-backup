# Сравнение с OTA-пакетом

> Источник: контекст ручной работы владельца. Проект не проверял пакет независимо. Это документация прежнего опыта, не обязательная функция v0.1.

## Пакет

| Параметр | Значение |
|---|---|
| Размер установленной версии | `67796480` байт |
| SHA-256 | `e1993924a438edb20cce370c6be3089a9426d8f3377874197301d450ef0ad854` |
| Формат | CPIO `070702`, несмотря на `.zip` в URL |
| Подпись `sw-description.sig` | Отдельно не проверялась |

Совпадение хешей не является криптографической проверкой происхождения пакета. Неизвестно, тот ли это пакет, который был установлен, и не изменялся ли он.

## TPL (mtd1)

Сохранённый `mtd1` состоит из двух половин по 1 MiB.

- Две половины побайтно одинаковы.
- Каждая половина: `952832` байта OTA-TPL + `95744` байта `FF`.
- `952832 + 95744 = 1048576`.

## BL2 (частичный mtd0)

- Первые `49152` байта частичного `mtd0` точно совпали с OTA-BL2.
- Остаток частичного файла до `260096` байт — `FF`.
- Полный первый слот и остальные семь слотов не проверены.

Это не делает частичный `mtd0` полным и не отменяет запрет на повторное чтение.

## Boot (mtd2)

- Первые `5777920` байт `mtd2` совпали с OTA `boot.img.encrypt`.
- Следующие `1536` байт совпали с продолжением CPIO:
  - `110` байт заголовка;
  - `15` байт имени с NUL;
  - `3` байта выравнивания;
  - `1408` байт начала `dt.img.encrypt`.
- Далее до конца `mtd2` — `FF`.

Код-кандидат SWUpdate 2019.11 содержит механизм чтения полной страницы из общего потока, который согласуется с этим хвостом. Но точная реализация установщика Яндекса неизвестна. Нельзя называть это доказанным дефектом конкретной версии Яндекса.

## Чего нельзя делать

- Не исправлять хвост.
- Не обрезать `mtd2` до «полезной» длины.
- Не дополнять файлы `FF`.
- Не считать совпадение с OTA доказательством корректности всего раздела.
- Не использовать эту страницу как инструкцию по модификации загрузчика.
